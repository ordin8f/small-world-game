# Small World — The Lost Ball

A dependency-free WebGL2 playtest episode for the Small World concept.

## Run locally

```bash
npm run verify
npm run serve
```

Open `http://localhost:8080`.

## Controls

- WASD / arrow keys: move
- Drag mouse: orbit camera
- Shift: run
- E / Space: interact
- R: restart episode
- F2: development emotion/state panel

## Scope

This is a disposable experience prototype, not the production engine foundation. It validates child-scale navigation, a social action loop, and the Emotional Lens before the episode is ported to PlayCanvas.
