# Concept Art Reference

[`visual-direction-contact-sheet.jpg`](visual-direction-contact-sheet.jpg) consolidates the refined concept studies for mood, composition, scale, lighting, and child-height framing.

It contains six reference situations:

- home / threshold;
- path / discovery;
- playground / scale;
- journey / child height;
- return / safety;
- overall visual direction.

These are not literal asset specifications. See [`../ART_DIRECTION.md`](../ART_DIRECTION.md) for the visual contract and [`../EMOTIONAL_LENS.md`](../EMOTIONAL_LENS.md) for how perception may modulate the same base world.
