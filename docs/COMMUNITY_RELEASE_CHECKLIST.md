# Community Release Checklist

- [ ] `npm run verify` passes on the release commit.
- [ ] Forward and right movement follow the visible camera direction.
- [ ] The garden opening is visibly and physically traversable.
- [ ] The episode can be completed without debug controls.
- [ ] Sound can be muted and motion can be reduced.
- [ ] Important spoken information appears as text.
- [ ] The feedback form does not upload data automatically.
- [ ] GitHub Pages deploys the verified static artifact.
- [ ] Testers receive the short community message rather than the full design history.
- [ ] Feedback is triaged by scale, readability, emotional timing, social meaning, pacing, and desire to continue.
